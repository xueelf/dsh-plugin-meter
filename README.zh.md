# dsh-plugin-meter

DeepSeek Harness（dsh）的费用计量插件。输入框下方的统计条显示当前会话的预估 API 费用，点开后按当前模型厂商显示余额或额度。插件面向 DSH 内置的模型厂商设计，目前接入 DeepSeek、OpenCode Go 和 Codex，其它厂商会提示没有额度数据源。

使用其他语言阅读：[English](./README.md) | 简体中文

## 显示内容

费用读数位于官方 token 读数右侧，样式与官方信息统计读数保持一致。前半段是时间：OpenCode Go 和 Codex 显示最近一次额度重置的倒计时，DeepSeek 显示当前价格时段和距离下一次切换的时间。后半段是当前会话的预估费用，例如 `1h 32m · US$0.07`。

费用读数要等第一条 Assistant 回复结算后才出现。新会话还没有用量时不显示，和官方统计读数一致。

DeepSeek 官方 API 的标签是当前价格时段，后面的数字是距离下一次切换的时间。空闲期显示 `空闲 3h 40m`，高峰期显示 `高峰 2h 15m`。倒计时每 30 秒更新。

点开读数会打开详情面板，字号、间距、边框和投影都和官方 Token 用量面板一致：

| 当前模型厂商  | 面板内容                                                                                |
| ------------- | --------------------------------------------------------------------------------------- |
| DeepSeek 官方 | 充值余额，赠送余额大于 0 时一起显示，例如 `¥100.00 CNY`。                               |
| OpenCode Go   | 固定的 5 小时、1 周、1 个月三个额度窗口。每行显示窗口名和已用百分比，悬停可看重置时间。 |
| OpenAI Codex  | 订阅返回的额度窗口。每行同样显示窗口和已用百分比，窗口数量和长度由订阅决定。            |
| 其它厂商      | 提示该厂商还没有接入额度数据源。                                                        |

面板跟随模型选择。提交后立刻切到新厂商，在 DeepSeek、OpenCode 和 Codex 之间切换时不会先闪一下旧厂商的行。面板与费用读数右对齐，并留在视口内。按 Escape 或点击面板外部会关闭，按 Escape 关闭后焦点回到费用读数。

如果会话里有无法定价的 token，面板底部会多一行「未定价」，只列 token 数（例如 `1,234,567 tok`），不计入总金额。

## 安装

你可以在 dsh 的插件管理器中，通过输入 `dsh-plugin-meter` 来进行安装。安装后插件在列表中以「费用计量」显示。

DSH 通过 pnpm 进行依赖管理，而 pnpm 的 [`minimumReleaseAge`](https://pnpm.io/zh/11.x/supply-chain-security) 策略会跳过发布时间未满规定时长（最多不会超过 24 小时）的版本，因此在安装插件时可能下载到较旧的版本。

如果你想马上使用最新版插件，可以直接输入版本号进行安装，例如 `dsh-plugin-meter@^0.1.0`。也可以等待一段时间，待新版本满足该策略后再按包名安装。

## 费用如何计算

每条已结算的 Assistant 消息按 token 用量和公开单价估算。金额是 API 等价费用，不是订阅费，也不是厂商实际扣款。

未命中缓存的输入、缓存读取、缓存写入和输出分别计价。DeepSeek 空闲时段按基准价，高峰时段单价翻倍。OpenCode Go 使用自己的固定目录价，不套 DeepSeek 的高峰倍数。

未知厂商或未知模型不猜价格，token 记为「未定价」，不计入金额。

## 已知限制

- 目前只支持 DeepSeek 官方 API、OpenCode Go 和 OpenAI Codex，其它厂商会显示提示。
- 金额是估算值。缓存写入档位、OpenCode 的实际计费、跨越高峰边界的请求，都可能让结果和厂商账单不同。
- 请求按 Assistant 消息的结算时间归入价格时段，不是厂商实际计费时刻。
- 价格阶梯按整条请求的 prompt token 数选择。
- 没有处理中国法定节假日，工作日节假日按普通工作日计价。
- Codex 按订阅收费，面板金额是 API 等价估算，不是按订阅费折算。
- Codex 的窗口数量和长度由订阅决定。
- DeepSeek 官方 API 只返回当前余额，没有累计消费。

## 常见问题

| 问题                                     | 说明                                                                                                                   |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 金额为什么和厂商账单不一样？             | 这里按公开单价和会话 token 估算，不是厂商实际扣款。缓存写入档位、OpenCode 的实际计费、跨高峰边界的请求都可能造成差异。 |
| 「未定价」是什么？                       | 当前厂商或模型没有可用的价格，或者对应阶梯缺失。这些 token 只列出数量，不计入金额。                                    |
| 切换模型后额度为什么没变？               | 额度数据属于厂商，不随同一厂商内的模型切换。换到别的厂商才会换额度源。                                                 |
| 面板显示「未配置」或「查询失败」怎么办？ | 当前厂商没有可用的账户凭据，或者接口、网络失败。检查 DSH 里的对应凭据后重新打开。                                      |
| Codex 订阅费为什么没有算进金额？         | 面板计算的是 API 等价费用，不把订阅费折算进金额。                                                                      |
